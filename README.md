# ChatBot Kelompok 5

Proyek ini adalah antarmuka ChatBot berbasis web dengan desain modern bertema **Royal Blue Technology**. Dibuat menggunakan HTML, CSS, dan JavaScript murni tanpa framework tambahan.

## 🎨 Fitur Desain

*   **Tema Teknologi/Cyberpunk**: Menggunakan nuansa warna biru royal (`#0044ff`) dan background luar angkasa yang dalam.
*   **Efek Glassmorphism**: Container chat transparan dengan efek blur (frosted glass) yang elegan.
*   **Grid Background 3D**: Animasi latar belakang berupa grid bergerak untuk memberikan kesan futuristik.
*   **Responsif**: Tampilan menyesuaikan ukuran layar, tanpa header navigasi (fullscreen mode).
*   **Font**: Menggunakan font Google 'Outfit' untuk keterbacaan yang modern dan bersih.
*   **Input & Tombol**: Desain input teks dan tombol kirim yang menyatu dengan tema, mendukung efek hover.

## 🛠️ Teknologi yang Digunakan

*   **HTML5**: Struktur halaman web.
*   **CSS3**: Styling lanjutan dengan animasi (`keyframes`), variabel CSS (`:root`), dan flexbox.
*   **JavaScript**: Logika sederhana untuk menangani input pengguna dan tampilan pesan (file `chat.js`).

## 📂 Struktur File

*   `index.html`: File utama yang berisi kerangka HTML.
*   `style.css`: File styling untuk tema Royal Blue dan animasi.
*   `chat.js`: Script untuk fungsi pengiriman pesan dan interaksi chat.
*   `profil.jpg`: (Opsional) Gambar profil untuk bot atau pengguna.
*   `wave.png`: Aset gambar untuk animasi gelombang di bagian bawah.

## 🚀 Cara Menjalankan

1.  Pastikan semua file (`index.html`, `style.css`, `chat.js`, dan aset gambar) berada dalam satu folder yang sama.
2.  Buka file `index.html` menggunakan browser web modern (Chrome, Firefox, Edge, dll).
3.  ChatBot siap digunakan!
